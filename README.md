# Clawd Pet 🦀

มินิเกมสำหรับ Claude Code: เลี้ยง **Clawd** (มาสคอตของ Claude Code) และช่วยกันตีบั๊ก!

## ติดตั้ง

```
/plugin install clawd-pet --marketplace RealzZne0/Test
```

ตอบ `y` เพื่อเพิ่ม marketplace แล้วเลือก scope (แนะนำ user)

## วิธีเล่น

พิมพ์ `/clawd` เพื่อเปิดหน้าต่างเกม

| ปุ่ม | ทำอะไร |
| --- | --- |
| `f` ให้อาหาร | อาหาร +25 |
| `p` ตีบั๊ก! | เริ่มมินิเกม: บั๊ก 🐛 จะย้ายช่องทุก 1.2 วินาที กด `1` `2` `3` ให้ตรงช่อง พลาด 3 ครั้งจบเกม |
| `s` นอน / ปลุก | ตอนหลับพลังงานจะฟื้นขึ้น |

- ค่าอาหาร พลังงาน ความสนุก ลดลงทุกนาที — อย่าลืมดูแล Clawd
- ทุกครั้งที่ Claude ใช้ tool (อ่านไฟล์, รันคำสั่ง ฯลฯ) Clawd ได้ XP — ครบ 100 XP เลเวลอัป 🎉
- ตีบั๊กโดนได้ XP และความสนุกเพิ่ม สถิติสูงสุดถูกบันทึกไว้ข้าม session
